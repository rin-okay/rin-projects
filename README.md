# rin's projects

Forge Neo extensions and little tools I've made or modified.

## Forge Neo extensions

### Prompt and generation tools

- [CFG Scheduler v1.4](extensions/CFG-SCHEDULER.md) - prompt-native, step-by-step CFG scheduling for txt2img, img2img, and independent Hires Fix passes using `<cfg:...>` and `<hrcfg:...>`.
  - [Download CFG Scheduler v1.4](extensions/forge-cfg-scheduler-v1.4.zip) (extract the included `forge-cfg-scheduler` folder into Forge Neo's `extensions/` folder).
- [Regional Prompter prompt-tag overlay v1.0.4](extensions/sd-webui-regional-prompter/README_TAGS.md) - tag-based regional prompting for Forge Neo. Requires the upstream Regional Prompter extension.
  - [Download the v1.0.4 overlay zip](extensions/regional-prompter-prompt-tag-overlay-v1.0.4.zip).

### Mobile extensions for Forge Neo

- [Gallery Restore](extensions/forge-gallery-restore/) - restore recent gallery results, generation parameters, and inactive Hires Fix settings after mobile browser interruptions.
- [Docker Manager](extensions/docker-manager/) - floating, movable docks for generation, gallery, Hires Fix, and other controls. Includes lock/hide tools and hot-refreshable dock modules.
- [Mobile Quality of Life](extensions/mobile-quality-of-life/) - mobile zoom, native selection menus, and collapsible Quick Settings.
- [Rin Theme](extensions/rin-theme/) - dark purple Rin Neon theme and Forge UI styling.

These are independent extensions. See the [extension index and installation notes](extensions/README.md).

## Tools

- [rin's regional prompting helper](extensions/regional-prompting-helper.html) - standalone HTML editor for the Regional Prompter prompt-tag overlay. Download and open it in your browser.
