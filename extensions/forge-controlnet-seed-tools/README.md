# ControlNet Seed Tools — Forge Neo

A standalone extension that adds opt-in preprocessor seed controls **inside each integrated ControlNet unit**. No core file is modified.

## Install

1. Extract this folder into `<Forge Neo>/extensions/forge-controlnet-seed-tools/`.
2. Restart Forge Neo (a UI refresh is insufficient).
3. Expand **ControlNet Integrated**, then select a ControlNet unit. The two extra seed controls appear after the unit's existing options.

Developed against the `neo` branch of `Haoming02/sd-webui-forge-classic`, as inspected on October 18, 2026. Forks and future changes to the integrated ControlNet script may require updates.

## Controls

- **Vary preprocessor per image** — unchecked by default. If checked, the selected preprocessor runs separately for every generated image; this includes each batch of a multi-batch job.
- **Preprocessor seed (-1 = image seed)** — `-1` means use the exact diffusion seed for each generated image when variation is enabled. Enter a nonnegative integer to use an independent seed instead.

| Vary per image | Seed | Result |
|---|---|---|
| Off | -1 | Native Forge Neo behavior, unchanged |
| On | -1 | Each map uses the corresponding diffusion image seed |
| Off | 5678 | One map per entire generation job using seed 5678 |
| On | 5678 | Different map per generated image, using 5678, 5679, 5680, etc. |

Seed increments are **global image positions** in the job, so with batch size 4, count 3, the second batch uses base+4 through base+7. Seeds wrap at 32 bits.

## Reproducibility example

Run batch size=4, count=1, base diffusion seed=100, with `Vary preprocessor per image` checked and ControlNet seed=-1. The maps use seeds 100, 101, 102, and 103. To regenerate the third image alone, set image seed=102, batch size=1, and leave these ControlNet settings intact: the ControlNet preprocessor map will be the same for image 102.

Alternatively, set independent ControlNet seed=4500 with variation **off** to reuse exactly the same randomized preprocessing regardless of diffusion seed or batch setup.

If using both an independent seed and per-image variation, the `base + image position` rule applies: re-generating an image alone needs the matching computed ControlNet seed, not the batch's original base seed.

## Compatibility and limitations

- The extension works with image-returning preprocessors, not just Shuffle. Randomness is seeded for NumPy, Python's random generator, and CPU PyTorch, and the previous state is restored after each preprocessing call.
- Preprocessors returning non-image data (such as certain embedding encoders) keep their native conditioning. These are reported in the console.
- Preprocessors relying on GPU-specific randomness, or with internal state/caches, are not guaranteed reproducible.
- Existing ControlNet preview/detected-map output remains generated by the native preprocessor pass, so it may **not reflect the alternative map**. The tensors fed into sampling do reflect the selected seed(s). The native pass means opted-in preprocessors currently execute once more than the theoretical minimum, which can impact processing time.
- Hires Fix uses the same per-image preprocessor map for its low-resolution and high-resolution passes, resized as needed. It is not shuffled again between passes.
- For ordinary deterministic preprocessors, the extra preprocessing is typically unnecessary. Leave the checkbox off and the seed at -1 for zero behavioral change.
- ControlNet settings are included in generation metadata when customized. When pasting infotext, the options are restored to the corresponding UI slot.
- This patch uses runtime hooks on Forge Neo's ControlNet implementation. It intentionally does not patch standalone ControlNet extensions or ComfyUI.

## Uninstall

Remove `<Forge Neo>/extensions/forge-controlnet-seed-tools/` and restart Forge Neo. No modified core files need restoration.
