# Forge Mobile Quick Settings

Standalone mobile-only UI extension for Forge Neo.

Features:
- Collapses Forge's top Quicksettings area under a `Quick Settings` accordion on phone-sized touch devices.
- The accordion starts closed on each fresh page load.
- Adds `Hide Styles bar` inside that accordion.
- `Hide Styles bar` defaults to checked and hides the main txt2img/img2img Styles dropdown + edit button row.
- The Styles preference is remembered in browser localStorage.
- Desktop presentation is unchanged.

This extension does not include Rin Tools, Dock Manager, mobile zoom, native-select replacement, or the Rin Neon theme.
